# Alipay-CampusRun（支付宝校园跑 · 通用版）

适用于 **Windows 11 x64 + WSA** 的支付宝校园跑通用版工具，支持内置 OpenStreetMap 地图手绘闭合路线、导入单段闭合 GPX、自定义配速与步频，并提供一键安装、卸载与故障诊断脚本。

## 下载与快速开始

> [!IMPORTANT]
> 请前往 **[GitHub Releases](https://github.com/tcrrry/Alipay-CampusRun/releases/latest)** 下载完整整合包 **`Alipay-CampusRun-v1.0.0.zip`**，勿直接克隆仓库后运行（仓库内不含超大依赖包）。

1. 确认系统为 **Windows 11 x64**，并在「任务管理器 → 性能 → CPU」中确认“虚拟化”已启用（若未开启需进入 BIOS/UEFI 开启 Intel VT-x / AMD SVM）。
2. 将下载的 `Alipay-CampusRun-v1.0.0.zip` **完整解压**到本地目录（不要在压缩包预览窗口中直接双击运行）。
3. 先阅读 `00-先看安装说明.txt` 与 `教程再这里，请务必查看/安装与使用详细说明.pdf`。
4. 双击运行 **`01-双击安装.cmd`** 按提示完成安装（若提示重启 Windows，重启后再次运行 `01-双击安装.cmd`）。
5. 安装完成后双击 **`02-装好后启动.cmd`** 打开控制窗口：
   - **路线设置**：可直接选择单段且首尾相距不超过 20 米的 GPX 文件；或点击「地图画路线」在内置 OpenStreetMap 底图上右键拖动、滚轮缩放（支持 WGS84 经纬度定位、地名搜索及底图切换）左键逐点绘制至少 3 个点后点击「闭合并使用」。
   - **运动参数**：按每公里分/秒填写配速、按每分钟步数填写步频（修改后自动保存在当前 Windows 用户下；开始操作可能重启 WSA，请提前保存安卓应用内工作）。

## 主要脚本说明

| 文件 | 说明 |
| --- | --- |
| `01-双击安装.cmd` | 一键安装环境、WSA 及配套应用（若电脑已有其他 WSA，会停止以避免覆盖原环境） |
| `02-装好后启动.cmd` | 启动控制面板，配置路线、配速与步频，提供“黑屏重开支付宝”、WSA 设置与 Iriun 摄像头入口 |
| `03-一键卸载.cmd` | 一键卸载环境与本次解压目录（卸载前请关闭 02 窗口，并将原 ZIP 与个人文件移出解压目录） |
| `04-故障诊断.cmd` | 复现异常后采集日志，在桌面生成诊断压缩包用于排查问题 |
| `99-手动安装（备用）.cmd` | 备用手动安装入口 |
| `常见问题与手动安装.md` | 常见环境问题与操作注意事项 |
