支付宝校园跑 正式版

开始前：
1. 适用 Windows 11 x64。检查任务管理器 → 性能 → CPU 中的“虚拟化”是否已启用。BIOS 中未开启时，需要根据电脑型号手动开启。
2. 将 ZIP 完整解压，不要在 ZIP 预览窗口内直接运行。
3. 打开“教程再这里，请务必查看”文件夹里的“安装与使用详细说明.pdf”，按第 1 页开始逐步安装。WSA 安装后才需要开启 WSA 内的开发人员模式。地图画路线使用下方的新步骤。
4. 如果电脑已经安装其他 WSA，安装程序会停止以避免覆盖原环境。

使用时：
- 双击“01-双击安装.cmd”，按照窗口和 PDF 的提示操作；如提示重启，重启后再次运行 01。
- 安装完成后，双击“02-装好后启动.cmd”。已有 GPX 文件可直接选择，路线应为单段且首尾相距不超过 20 米。
- 需要新画路线时，点击“地图画路线”。内置 OpenStreetMap 底图需要联网。右键拖动、滚轮放大，也可输入 WGS84 纬度和经度后点“定位”。放大后沿跑道左键逐点画线，至少选三个点，再点“闭合并使用”。路线直接回到控制窗口，无需 GPX 文件。
- 配速按每公里的分钟、秒填写；步频按每分钟步数填写。开始操作可能重启 WSA，请提前保存安卓应用中的工作。
- 点击“闭合并使用”会在当前 Windows 用户下记住这条路线。重开控制窗口会自动恢复；再次打开地图可继续修改。想重画可点“清空画板”，画好并确认后会替换上次保存的路线。
- 地图默认使用免 Key 的 OSM 德国底图，覆盖全球地区；可在工具栏切换回 OSM 标准底图。关闭代理后，可用浏览器打开 https://tile.openstreetmap.de/5/25/12.png 检查德国底图是否可直连。若仍失败，请记录地图显示的错误代码。
- 使用结束后点击停止。卸载前关闭 02 控制窗口，将个人文件和原 ZIP 放在解压目录外，再双击“03-一键卸载.cmd”。确认后会移除 WSA 和本次解压目录。

首次打开时路线为空。画完点“闭合并使用”，主窗口显示“地图路线（…点）”即完成回填。

第 3 步：在 WSA 的 Advanced settings 开启 Developer mode，再点 Manage developer settings，直接打开 Android 开发者选项。
第 4 步：首次启用 Vector 后 WSA 会重启。出现 Allow 时勾选始终允许，再点 Allow。仅当提示未授权且没有弹窗时，才打开 Manage developer settings 并关开一次 USB 调试。
若提示暂未取得 Root，在 Android 开发者选项关开一次 USB 调试，然后立即回到黑色窗口按 Enter。若出现 ADB Allow，确认授权。若 Magisk 弹出 Shell 超级用户请求，再点允许。第 6 步检查通过后直接结束。

安装时右上角会出现可收起的置顶提示；若授权窗口在后面，请从任务栏切换到 WSA、Magisk 或系统提示。
地图可点击“搜索地名”，服务无需密钥但需联网，部分网络可能无法访问；失败可使用经纬度定位。
配速和步频在启动模拟时生效；运行中修改不会实时生效，请先结束跑步并停止，再修改并重新开始。
02 控制窗口：
- 配速和步频修改后会保存在当前 Windows 用户下，下次打开 02 自动恢复。
- 02 的“开始”或“黑屏重开支付宝”在连接时发现 ADB 未授权，会尝试自动打开 WSA 设置。也可点击 02 窗口下方的“WSA 设置”，或按 Win+R 输入 wsa-settings: 后回车。
- 如果授权弹窗已经出现，勾选始终允许并点击 Allow。没有弹窗时，在 WSA 设置打开 Advanced settings（高级设置），确认 Developer mode 已开启，再点 Manage developer settings。进入 Android 开发者选项，关闭再开启“USB 调试”。点击 Allow 后返回 02，若操作已超时则再点一次原按钮。
- 支付宝闪退或黑屏时，等当前操作结束后点击“黑屏重开支付宝”。若模拟已启动，会保留当前定位服务和参数；若模拟已停止，则按 02 当前选中的路线、配速和步频启动模拟。看到“已就绪”后再进入校园跑。若仍黑屏，可先运行 04 采集现场。
- “Iriun 手机摄像头”会启动已安装的 Windows 客户端。未安装时打开 Iriun 官网。连接手机后先用 Windows 相机验证画面。WSA 能否识别该相机取决于实际环境。

遇到问题时使用 04 故障诊断
1. 双击主包内的“04-故障诊断.cmd”。通常直接回车检查当前解压目录。如果旧版卸载失败，把新版解压到另一处，从新版运行 04，输入 1 后选中旧版解压目录。
2. 按窗口提示重试刚才失败的操作。错误再次出现后，回到 04 按回车采集。若支付宝已经黑屏，保留黑屏窗口和 WSA，直接按回车即可。若安装或卸载窗口有报错，可以把报错原文贴入 04。
3. 如果采集时出现 USB 调试授权，点击 Allow 后可再跑一次 04 补采 Android 日志。
4. 将桌面生成的“支付宝校园跑诊断-日期时间.zip”发给提供安装包的人。

本包内置支付宝 12.12.56.8000。安装会选择 arm64-v8a。已安装较新 64 位版本时会保留。若仍闪退，请尽快运行 04，发送诊断包。
